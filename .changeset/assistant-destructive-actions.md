The assistant can now propose deleting a project, an architecture or agent conventions, changing who can open an architecture, and replacing an architecture's share link or access code. A deletion's card lists what goes with it (architectures, diagrams, agent conventions, code maps, rules) and a sharing change shows the visibility before and after; a change that cannot be undone has a red accept button. The assistant never sees a share link or an access code: you read the new ones on the architecture's sharing screen.
