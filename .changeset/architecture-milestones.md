An architecture now has a history: the « History » button of the editor keeps the current state of all its views as a named milestone (a release, a target, a state before a migration). A milestone can be compared, view by view, with the current state or with another milestone, restored (the views go back to it, and the ones added since are deleted) or deleted. An architecture keeps at most fifty milestones.
