The assistant floats over every page: one launcher in the corner opens it in a card that never takes room beside the page, in place of the "Assistant" buttons of the header, of an architecture's toolbar and of a project's Code tab (drawing from a code map moves to the map's menu). The "About" picker is gone: one architecture alone goes to its diagrams, anything else is left to the assistant.
