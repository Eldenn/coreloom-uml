The admin runs the skills commands from the Skills page: start the skills.sh search, scan the copies waiting for a verdict or one copy again, stop suggesting a skill (with a reason) or suggest it again. "Sync now" in a skill's sheet replaces "Copy now": it reads the skill's audits and its pin again before copying it, for any skill that is not blocked.
