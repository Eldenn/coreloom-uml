You can attach a text file (Markdown, plain text, JSON, YAML…, up to 60,000 characters) to a message of the assistant. In « Auto », it reads the file and proposes what it calls for, each as a card you accept or reject: a project, an architecture, and new agent conventions with the rules the file states (every rule listed on the card, ready-made rules of the catalog preferred), and it names the skills of the catalog that fit, with their links. The views of an architecture are drawn afterwards: accept the architecture, then ask for its views with the file attached again. The file goes to your model with that message only: the conversation keeps its name, never its content.
