With code maps on, the assistant reads a project's code maps, how its diagrams match the code and the links of a diagram, and can propose to map a GitHub repository (its full address, branch and follow shown on the card), delete a code map or a conformance review, stop following a repository, add or remove links between a diagram and the code (only the links it names change, each one listed on the card), and mark a review finding done, dismissed or open again. Nothing runs before you accept: the repository is only read once you accept the import. Starting a review, drawing from code and uploading a map stay on the Code tab.
